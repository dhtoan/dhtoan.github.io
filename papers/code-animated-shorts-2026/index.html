Code-Animated Shorts from Generative AI Stills: A Practitioner Case Study on a DIY YouTube Channel

Do Huy Toan · Independent researcher, Delaware, USA · ORCID 0009-0007-5803-4405

Download PDF DOI 10.5281/zenodo.23888335

Abstract

Solo creators increasingly combine generative AI with their own tooling to produce short-form video at volume. This practitioner report describes a pipeline built and run by one person: an AI image model produces still artwork, and all motion, captions and timing are written as deterministic HTML and JavaScript, rendered frame by frame in a headless browser and encoded with FFmpeg. We report the architecture, an engineering failure that matters to anyone rendering video from a browser (a memory leak in Playwright's synchronous API on Python 3.14), and an observational comparison on one YouTube channel. Eighteen Shorts produced with the pipeline between 15 and 20 October 2026 averaged 2.5K views (craft line, n = 7) and 1.2K views (illustrated-map line, n = 11), with 37% and 28% of viewers choosing to watch rather than swipe away. In the same month, 10–11-second craft Shorts built from AI-generated video clips reached 26K to 3.5M views with about 50% viewed. We discuss why reproducible, code-driven motion did not win in the short-form feed, where it remains useful, and the limits of single-channel evidence.
